## Decisions (do not re-litigate)

- **Units**: one conversion model, chainId-derived. `unitsPerHbar` 1e8 on Hedera (tinybars),
  1e18 local (wei). `relayScale = 1e18 / unitsPerHbar` (1e10 / 1). Frontend sends
  `msg.value = requiredNative * relayScale`; helper unit-tested. Never from env vars.
- **HCS**: client sends only `txHash`; server verifies receipt/events over RPC before submit.
  Routes `POST /api/hcs` + `GET /api/hcs`. **No rate limiter.**
- **Finalize**: `roundEndsAt = block.timestamp + roundDuration`; payout
  `min(pot, address(this).balance)` in the verified unit.
- **README Limitations** first item: member who already received the pot can stop contributing
  (no collateral); security deposit = future work.
- **Docs**: PLAN/RESEARCH move to `docs/` in Phase 3; Handoff stays at root.
- npm-only template: keep every command as `npm run X -w @sh/pkg --` (CLI rewrites md,
  skips tokens named `run`); no yarn/foundry/husky leftovers; root `.npmrc`
  `legacy-peer-deps=true`.
- Scaffold conventions: `@sh/hardhat`/`@sh/nextjs`, `useScaffoldReadContract`/
  `useScaffoldWriteContract`, `~~/` alias, `@scaffold-hbar-ui/components`, DaisyUI,
  `deployedContracts.ts` generated by `generateTsAbis`.
- Deployer keys via `npx hardhat run --network hederaTestnet` (interactive prompts avoided).
